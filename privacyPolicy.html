Privacy Policy

Study Buddy is an educations web application created as a final semester project for ITSE 2302 (Intermediate Web Programming) course at Collin College. The purpose of this website is to demonstrate the use of HTML5, CSS, and JavaScript in the development of an interactive website.

The contents of this website are intended solely for educational purposes and demonstrates the use of creating an interactive website using HTML5, CSS, and JavaScript learned throughout the course.

Information Collection

This website does not have user accounts, registration. Any assignment and grade information entered by the user is stored locally within the user's web browser to support the functionality of the application. This informaion is not collected, or stored on external servers.

This website does not use tracking technologies, analytics, advertising, or other methods to monitor visitor traffic.

Some educational resources or external links may direct users to third-party websites. Once a visitor leaves this website, the privacy policy of those external websites take effect. Visitors are encouraged to review those policies before sharing any information.
